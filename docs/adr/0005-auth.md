# ADR-0005: Authentication and authorisation

Status: Accepted  
Date: 2026-11-05

## Decision
Short-lived JWT access tokens with rotating refresh tokens stored hashed. Passwords use argon2. API keys are per-user and hashed at rest. Roles are admin, reviewer, viewer. Every document query takes an org_id at the repository layer, and a missing or foreign document returns 404.

## Why
Scoping in the repository means a forgotten router check cannot leak across organisations. 404 avoids confirming that another organisation's document exists.
