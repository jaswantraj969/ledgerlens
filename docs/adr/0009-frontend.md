# ADR-0009: Frontend library

Status: Accepted  
Date: 2026-11-05

## Decision
React, TypeScript, Vite, Tailwind, with hand-written components in place of shadcn/ui until a need appears. pdf.js renders pages. The API client is hand-written with zod validation.

## Why
The review screen is mostly one custom viewer. R11 favours adding fewer dependencies.
